# 🤖 Deriv ML Algorithmic Trading Bot

Автоматизований торговий бот для бінарних опціонів / цифрових контрактів на платформі **Deriv API** з багаторівневою індикаторною стратегією, фільтрацією сигналів за допомогою машинної навчання (**XGBoost**) та повним логуванням результатів у **PostgreSQL**.

---

## 🚀 Основні можливості

- **Асинхронне сканування (asyncio + websockets):** Паралельний аналіз свічкових даних для форекс-пар та металів (`frxEURUSD`, `frxGBPUSD`, `frxUSDJPY`, `frxAUDUSD`, `frxXAUUSD`).
- **Мульти-індикаторна стратегія:** Аналіз ринку на 15-хвилинних таймфреймах за допомогою:
  - **RSI (Relative Strength Index):** Визначення зон перекупленості/перепроданості.
  - **EMA (Exponential Moving Average):** Визначення напрямку глобального тренду.
  - **Bollinger Bands:** Оцінка волатильності та імпульсних пробоїв ціни.
- **🧠 ML-фільтрація сигналів (XGBoost Classifier):**
  - Оцінка ймовірності виграшу у кожній угоді перед входом на основі історичного датасету.
  - Угода відкривається тільки при перевищенні заданого порогу ймовірності (за замовчуванням $\ge 55\%$).
  - Враховує часові сесії (години, дні тижня), екстремуми RSI та баланс голосів індикаторів.
- **Гарантований таймер експірації:** Стійкий алгоритм `TraderManager`, який запобігає зависанню WebSocket-з'єднання під час 15-хвилинної очікування угоди.
- **PostgreSQL Логування:** Запис кожного входу, початкових показників індикаторів, стану ринку та підсумкового профіту для подальшого донавчання ML v2.
- **Telegram Notifier & Stats:** Сповіщення у реальному часі про входи, результати угод та інтерактивні команди (`/stats`, `/help`).

---

## 🛠 Технологічний стек

- **Python 3.10+** (`asyncio`, `websockets`, `aiohttp`)
- **Machine Learning:** `xgboost`, `scikit-learn`, `joblib`, `pandas`
- **Technical Analysis:** `ta`
- **Database:** `asyncpg` (PostgreSQL)
- **Telegram Bot API:** `aiogram 3.x`

## 📁 Структура проекту

├── main.py              # Головний асинхронний цикл сканування та оркестрації
├── ml_filter.py         # Модуль класифікації та фільтрації угод через XGBoost
├── train_model.py       # Скрипт для (ре)навчання ML-моделі на накопиченому датасеті
├── strategy.py          # Технічний аналіз свічок (RSI, EMA, Bollinger Bands)
├── trader.py            # Виконання угод через Deriv WebSocket API та таймер експірації
├── market.py            # Отримання свічкових даних від брокера
├── account.py           # Управління авторизацією та підключенням до Deriv
├── database.py          # Менеджер з'єднань PostgreSQL та логування угод
├── tg_bot.py            # Сповіщення та Telegram-команди бота
├── export_dataset.py    # Скрипт вивантаження історії угод у CSV для ML
├── config.py            # Конфігурація змінних оточення
├── xgb_model.pkl        # Бінарний файл навченої XGBoost моделі
├── model_features.pkl   # Збережений порядок фічей для ML-моделі
└── requirements.txt     # Залежності проекту
